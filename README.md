Personal Introduction Page

A simple, responsive single-page personal website built for Day 2 of the Veda Technology Web Development internship.

About the project

The page introduces me, Anna Thantsha, a Computer Science student at Tshwane University of Technology. It includes my name, profile picture, introduction, skills, hobbies and contact details.

Features
Single-page layout with Profile, About Me, My Skills, My Hobbies and Contact Me sections
Semantic HTML5 structure (header, main, section, footer)
Skills shown as a styled list and hobbies as a bulleted list
Consistent colours, typography and spacing using CSS variables
Responsive design with a media query for mobile screens
Tools used
HTML5
CSS3
Visual Studio Code
